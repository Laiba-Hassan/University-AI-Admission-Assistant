# antislop audit 001 — 2026-11-07

**Scope:** `apps/landing` (the Enrollium marketing site) — the only complete, finished UI produced this session.
**Mode:** AFTER (audit existing work). Nothing below has been changed. Reply with the numbers you want fixed.

---

## HIGH (Hard Gate)

**1. Em dash used throughout the copy — R-02**
`&mdash;` appears in `Hero.jsx`, `Problem.jsx`, `Demo.jsx`, and `Contact.jsx` (e.g. "in English, Roman Urdu, or Urdu &mdash; and never states a figure..."). R-02 forbids the em dash character in agent-written text outright.
*Fix:* rewrite each sentence with a comma, period, or parentheses instead.

**2. Several tap targets fall under the 44px minimum — R-03 / R-39**
`.nav-menu-toggle` is 40×40px. `.nav-cta` / `.copy-btn` sit around ~36px tall by default and shrink further (9px/13px padding, 13px font) under the `max-width: 480px` rule — well under the 44px tap-target floor on the exact screens that need it most.
*Fix:* bump these to a true 44×44px minimum, especially the hamburger toggle and the mobile CTA.

**3. Mobile nav menu has no Escape-to-close and no dialog semantics — R-26 / R-32**
The hamburger menu's backdrop + sheet function as a modal overlay (dimmed backdrop, tap-outside-to-close) but there's no `keydown` handler for Escape, no `role="dialog"`/`aria-modal="true"`, and no focus trap/return-focus-to-toggle behavior.
*Fix:* add an Escape handler, dialog ARIA, and focus management.

---

## MEDIUM (Purpose-Gate — technique allowed, reason missing)

**4. Primary buttons have no hover/active state — R-39**
`.btn-primary`, `.btn-secondary`, `.nav-cta`, and `.copy-btn` only get `cursor: pointer`; none define a `:hover` or `:active` visual change in `globals.css`. Every primary CTA on the page currently gives zero feedback on hover.
*Fix:* add a subtle hover/active treatment (opacity, background shift, or border change) to each.

**5. Hero eyebrow badge matches the flagged "badge above the headline" pattern — R-09**
"● AI ADMISSIONS ASSISTANT FOR UNIVERSITIES" — dot + uppercase + pill, sitting directly above the H1 — is the exact shape Part 1 calls out ("Eyebrow Badge Above the Headline"), and it restates category info the headline and hero copy already establish. No written functional reason exists for keeping it.
*Fix:* either cut it, or give it a real job (e.g. an actual live-status indicator) and write down why.

**6. Feature cards are uniform with no written hierarchy reason — R-14 / R-31**
All four cards in `Features.jsx` share identical size, icon-box treatment (36×36, same bg), and padding (26px) — the "Copy-Paste Feature Cards" shape from Part 1. The icons themselves are genuinely relevant to their content (that part is fine), but nothing in the code says why all four carry equal visual weight.
*Fix:* either write the one-line reason (e.g. "all four capabilities are equally weighted, none is the lead feature") or introduce deliberate size/weight variation.

## LOW (Quality Locks / performance)

**7. Hero photo and small logos skip explicit performance hints — R-40**
The hero background photo (`pk3.jpg`, the largest above-the-fold visual) has no `fetchpriority="high"`. The nav/footer logo `<img>` tags are sized only via CSS (no `width`/`height` attributes), so there's no CLS safety net if CSS loads late.
*Fix:* add `fetchpriority="high"` to the hero photo; add explicit `width`/`height` to the logo images.

**8. Unused light-theme tokens with no way to reach them — R-21**
`:root[data-theme="light"]` defines a full second palette, but nothing in the UI ever sets `data-theme="light"` — no toggle exists. (You did explicitly direct the dark-only look earlier this session, so this isn't a R-37 violation — just dead CSS nobody has visually verified.)
*Fix:* either wire up a real toggle, or delete the unused light tokens to stop carrying unverified dead code.

**9. No explicit ENERGY/RHYTHM/MOTION dial was declared — R-37**
Direction existed (match the real product's brand, reuse its tokens) and was followed, but the formal Design Read step was never stated out loud. Reading the shipped result back: roughly **ENERGY 2 / RHYTHM 2 / MOTION 2** (calm-professional, a few compositional breaks like the hero photo band, restrained scroll-reveal + hover motion).
*Fix:* none required — this is a process note for next time, not a defect in the current page.

## Not flagged (checked, passed)

- No em dash carve-out issues elsewhere, no fake stats/testimonials, no fabricated claims, no dead nav links (`#problem`/`#how`/`#features`/`#demo` all resolve to real sections), no generic AI buzzwords ("seamless", "revolutionary", "AI-powered" as a marketing phrase, etc.), no 3-tier pricing / fake "Trusted by" bar / 4-column template footer, border radius is deliberately varied (not pill-everything), palette stays within the core+accent budget, and the chat-bubble asymmetric corner radius on the proof card is a genuine, repeated identity motif.
